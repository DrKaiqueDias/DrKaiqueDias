## Selected work

### Conversational AI · Customer validation

[**Mia — Prompt Engineering Case Study**](https://github.com/DrKaiqueDias/Teste-Prompt-Engineer---Monest)

A customer-validation conversation designed for a prompt engineering assessment. The public repository includes **Handlebars templates**, CPF/CNPJ variants, simulated scenarios, risk analysis, and a proposed evaluation and iteration process.

The design separates model instructions from integration controls, with attention to tool responses, retry limits, privacy, and a customer's choice to stop. This is a specification with simulations, not a live banking integration.

### Health technology · Blockchain-based MVP

Built a healthcare data MVP combining **blockchain, AI facial recognition, patient-consented data sharing, and smart-contract traceability**. This work reflects my interest in connecting technical innovation with data governance and practical user needs.
